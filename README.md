
# Python Personal Data Collector 

This is a simple Python project that collects basic information from the user and demonstrates different Python data types.

## Features

- Takes user's name
- Takes age
- Takes height
- Takes favourite number
- Converts input into required data types
- Calculates approximate birth year
- Displays data types using `type()`
- Displays memory addresses using `id()`

## Technologies Used

- Python

## Concepts Used

- Variables
- User Input
- String
- Integer
- Float
- Type Conversion
- type()
- id()
- Basic Calculations

## How to Run

1. Install Python.
2. Open the project in VS Code or any Python editor.
3. Run `personal_data_collector.py`.
4. Enter the required information.

## Project Output

The program displays the entered information along with its data type, memory address, and approximate birth year.
